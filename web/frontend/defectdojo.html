Configure Credentials

How to Configure

Taintlace uses the system keyring (or authoritative environment variables) to encrypt and store integration credentials. This keeps sensitive API tokens safe off web browsers.

Set Credentials via CLI

Open your terminal in the repository and run:

python cli.py configure-defectdojo

The wizard will verify connection endpoints and securely commit keys to the host keychain.

Autorun Environment Setup

Alternatively, you can export keys as standard environment variables in your .env file:

DEFECTDOJO_URL=http://localhost:8080
DEFECTDOJO_API_KEY=your_secure_api_token
DEFECTDOJO_ENGAGEMENT_ID=1
